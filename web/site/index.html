ZrnoThe camera's effect code, running in your browser

Photo

Plug the camera in with Zrno running and use Connect camera, in Chrome or Edge. Each shot downloads when you open it, and opens with the look the camera gave it. On a Mac, run killall ptpcamerad in Terminal first. You can also drop the card or a folder from it here.

Each backup keeps the camera's white balance in a .SET file beside it. Temperature warms or cools from there, Tint moves between green and magenta.

Files stay on this computer: decoding and grading run here, nothing is uploaded.
